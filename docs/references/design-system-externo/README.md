# Fontes externas de design system

Estes arquivos foram recebidos de outro projeto em 2026-08-30 e são mantidos somente como material de consulta. Eles não são configuração ativa, não definem convenções obrigatórias deste repositório e não devem ser importados pela aplicação.

- `fontes/`: referências visuais e de padrões de front-end que podem inspirar decisões futuras, sempre sujeitas à arquitetura, acessibilidade e segurança deste projeto.
- `arquivados/`: material incompatível com a autenticação local atual, preservado apenas para rastreabilidade.

A configuração Tailwind ativa está em `frontend/tailwind.config.ts`. A decisão de uso restrito ao refinamento visual está documentada em [referencia-design-system-tailwind-shadcn.md](../../architecture/referencia-design-system-tailwind-shadcn.md).
